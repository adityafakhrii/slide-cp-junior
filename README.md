# CODEPOLITAN Junior — Slide Presentasi

Workspace khusus untuk pembuatan slide presentasi program **CODEPOLITAN Junior** berbasis `open-slide`.

## Struktur Folder

- **`materi/`** — Bahan/isi materi slide presentasi per pertemuan.
- **`design-branding/`** — Panduan desain, palet warna, tipografi, maskot Biko, dan standar komponen UI.
- **`slides/`** — Deck presentasi interaktif (React + SVG + Speaker Notes):
  - `pertemuan-1-kenalan-sama-laptop-ajaibku/` — Pertemuan 1 (10 slide).

## Menjalankan Preview Lokal

```bash
npm run dev
```

Lalu buka [http://localhost:5173/s/pertemuan-1-kenalan-sama-laptop-ajaibku](http://localhost:5173/s/pertemuan-1-kenalan-sama-laptop-ajaibku) di browser.
